# 🚀 Adremix AI - المحرك الموحد (Unified Engine)

مرحباً بك في مستودع **Adremix AI - المحرك الموحد**. هذا المجلد يحتوي على المحرك الخلفي (Core Engine) المكتوب بلغة Python لتشغيل عمليات تحليل الفجوة التسويقية (Gap Analysis)، تشخيص جودة الإعلانات (Ad Doctor)، وتوقع معدلات تفاعل الجمهور وتحويل المبيعات (Performance Predictor) باستخدام نماذج الذكاء الاصطناعي المتطورة.

---

## 🛠️ دليل تشغيل المحرك محلياً (Local Setup Guide)

اتبع الخطوات التالية لإعداد البيئة وتشغيل المحرك على جهازك المحلي:

### 1. إنشاء وتفعيل البيئة الافتراضية (Virtual Environment)
يُنصح دائماً باستخدام بيئة افتراضية لعزل مكتبات المشروع:

* **على أنظمة Linux / macOS:**
  ```bash
  python3 -m venv venv
  source venv/bin/activate
  ```

* **على نظام Windows:**
  ```bash
  python -m venv venv
  venv\Scripts\activate
  ```

### 2. تثبيت المكتبات المطلوبة (Install Dependencies)
قم بتثبيت جميع الاعتمادات المحددة في ملف `requirements.txt`:
```bash
pip install -r requirements.txt
```

### 3. إعداد مفتاح بيئة التشغيل (Configuration)
قم بإنشاء ملف `.env` في هذا المجلد (أو في جذر المشروع) وأضف مفتاح API الخاص بـ Google Gemini:
```env
GEMINI_API_KEY=your_gemini_api_key_here
```

### 4. تشغيل المحرك (Run the Engine)
قم بتشغيل الملف الرئيسي للمحرك لبدء دورة التحليل والحملة الإعلانية الموحدة:
```bash
python main.py
```

---

## 📂 هيكلية المجلد (Directory Structure)
* `main.py`: المدخل الرئيسي لتشغيل المحرك الموحد وحفظ التقارير.
* `config.py`: ملف الإعدادات وإدارة البيئة والتحقق من المفاتيح.
* `engine/`:
  * `gap_analyzer.py`: كشف الفراغ الاستراتيجي والزوايا غير المستغلة في السوق.
  * `ad_doctor.py`: تشخيص جودة النسخة الإعلانية ووصف العلاج المناسب.
  * `predictor.py`: محاكاة الأرقام المتوقعة للوصول والتفاعل والمبيعات.
  * `campaign_runner.py`: المنسق الموحد (Orchestrator) الذي يربط جميع هذه الخدمات معاً.
* `models/schemas.py`: نماذج البيانات المهيكلة باستخدام Pydantic لضمان تكامل المخرجات.
* `utils/gemini_client.py`: عميل مخصص للاتصال بـ Gemini API وإرجاع مخرجات مهيكلة بالكامل.

---

## 📄 مخرجات التشغيل
عند تشغيل المحرك، سيقوم بإنشاء مجلد `outputs/` يحفظ فيه تقارير الحملات بصيغة JSON مهيكلة بالكامل تحتوي على تفاصيل زوايا السوق المقترحة، النسخ الإعلانية المولدة، تشخيص الأخطاء، ونسب النجاح المتوقعة.
